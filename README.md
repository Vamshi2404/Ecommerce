# NxtTrendz – E-Commerce Web Application

A responsive e-commerce web application built using React.js, featuring product browsing, authentication, protected routes, and product sorting.

**Live Demo:** [NxtTrendz](https://nxttrendz-375.vercel.app/)

**GitHub Repository:** [NxtTrendz-2](https://github.com/Saikumar375-web/NxtTrendz-2)

---

## Overview

NxtTrendz is a React-based e-commerce application developed to demonstrate modern frontend development practices. It provides a shopping interface with product listings, authentication functionality, protected navigation, and reusable UI components.

The project focuses on building maintainable React applications, handling navigation between pages, and creating responsive user interfaces.

## Features

- **Product Browsing:** View and explore available products.
- **User Authentication:** Supports user login and authentication-related functionality.
- **Protected Routes:** Restricts access to protected pages based on authentication status.
- **Product Sorting:** Organizes products using available sorting options.
- **Client-Side Routing:** Enables navigation between pages using React Router.
- **Reusable Components:** Uses reusable React components for maintainable code.
- **Responsive Design:** Provides layouts designed for different screen sizes.
- **Loading Indicators:** Displays loading feedback during asynchronous operations.

## Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Routing:** React Router
- **Build Tool:** Vite
- **Authentication Cookie Handling:** js-cookie
- **Icons:** React Icons
- **Loading Indicators:** React Spinners
- **Version Control:** Git and GitHub
- **Deployment:** Vercel

## Getting Started

Follow these instructions to run the application locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Saikumar375-web/NxtTrendz-2.git
```

**2. Navigate to the project directory**

```bash
cd NxtTrendz-2
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

## Available Scripts
